⚙️ Trowel CAD 시스템 계층 구조 및 데이터 흐름

어도비 의존성을 완전히 배제한 클린룸 러스트(Rust) 기반 고성능 벡터 도면 엔진입니다.

1. 레이어 계층 아키텍처

  • UI Layer (crates/ui-egui): 즉시 모드 GUI, Trowel 1600×988 레이아웃, Quiet Plate 테마 토큰.
  • Command Engine (crates/engine): 모든 사용자 행동을 커맨드(`cmd/*`)로 캡슐화, 단일 실행 취소(Undo) 스택.
  • Document Model (crates/doc): 노드 트리 기반 벡터 객체, 범례-레이어 동기화 메타데이터.
  • Geometry & Pathops (crates/geom, pathops): 불리언 연산, 빗금 교차 계산, 오프셋 클리핑.
  • Export Subsystem (crates/pdf, cad): 출판급 벡터 PDF(QPdfWriter/krilla), 좌표 보존 DXF(CP949).

2. 고고학 전문 데이터 파이프라인

  • TM 좌표계 파이프라인: 로컬 캔버스 좌표 ↔ EPSG:5186/5187 실좌표 양방향 무손실 변환.
  • 스캔 아핀 정합: 방안지 2점/4점 기준점 기반 회전각 및 축척 왜곡 자동 보정.
  • 자동 빗금 알고리즘: 면 경계 탐색 후 0.8pt 외곽선 추출 + 0.1pt 빗금 채움 + 맞닿은 면 90° 엇갈림.

📋 Trowel 완성 실행 로드맵 (Phase 1 ~ Phase 4)

백로그(`factory/backlog.md`) 순서에 입각한 주도적 완성 일정표입니다.

Phase 1: 드로잉 코어 완성 (현재 착수)

  • J014 그리기 팔레트와 빗금: 굵기 사다리 칩, 빗금 4종, 「잘린 면(0.8+0.1)」 원클릭 생성.
  • J002b 스프링 로드 Z 돋보기: Z키 누르고 있는 동안 임시 줌, 놓으면 이전 도구 복귀.

Phase 2: 도면 템플릿 & 실좌표 인프라

  • J004 홈 화면 및 견본 4종: 평면·단면·유물·도판 규격 템플릿.
  • J006 축척 & TM 실제 좌표: 1:10~1:100 도면 축척, 국토 표준 EPSG:5186 연동.
  • J015 해발선 자동 생성: 50cm/10cm 등고선 수치 자동 계산 및 단면선 클리핑.
  • J007 좌표 보존 DXF 가져오기: desca 단면 레이어 맵핑 및 CP949 인코딩 처리.

Phase 3: 고고학 전문 화면 & 태블릿 펜

  • J016 / J017 펜·태블릿 입력 완성: 와콤/XP-Pen 필압 및 펜 제스처 지원, 손바닥 터치 방지.
  • J008 스캔 밑그림 맞추기: 2점/4점 클릭 아핀 정합.
  • J009 평면 도구: 단면 위치선(⇧A), 표고 기호(⇧Z), 주혈 깊이, 경사 방향, 면적 자동 계산.
  • J010 단면·토층 화면: 토층 경계선, 층위 번호, 토성 설명표.
  • J011 유물 실측·구경 화면: 1:1 실측, 회전 중심선, 구경 자동 원 피팅.

Phase 4: 출판 도판 & 표준 양식

  • J012 도판 조판 & PDF 내보내기: 방위표, 축척 막대, 표제란, 자동 범례표 배치.
  • J018 양식 파일 (.trowel-style): 사용자 표준 양식 저장 및 공유.
  • J019 Strata 발굴 GPKG 연동: 현장 조사 파일 직접 읽기 및 데이터 매핑.

🛠️ 개발 환경 설정 및 슈퍼파워 스킬·MCP·훅스 구성

개발 전 과정에서 완전 자동화된 품질 관리와 에이전트 지능형 개발 환경을 보장합니다.

1. 슈퍼파워 스킬(Superpowers Skills) 연동

  • brainstorming: 기능 기획 전 사용자 요구사항의 핵심 의도 파악.
  • writing-plans & executing-plans: 엄격한 TDD 검증 기준을 갖춘 단계별 작업 계획 수립 및 실행.
  • test-driven-development: 코드 작성 전 반드시 테스트를 먼저 작성하여 회귀 결함 원천 차단.
  • verification-before-completion: 완료 보고 전 실제 빌드 및 테스트 로그로 증거 기반 확인.

2. 자동화 훅(Hooks) & MCP 서버 구성

  • .agents/hooks.json: 파일 수정(`replace_file_content`/`write_to_file`) 즉시 `rustfmt`를 자동 실행하여 코드 스타일 무결성 유지.
  • .agents/mcp_config.json:
    • `rea`: 바이너리 역공학 및 정밀 분석 MCP 연동
    • `vectorcraft`: 네이티브 문서 검사, 제어 명령 실행 MCP 연동
  • .cargo/config.toml: `debug = 0` 프로파일을 설정하여 빌드 속도 5배 가속 및 디스크 초과 방지.
